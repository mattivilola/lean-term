# Perf snapshot baseline — 0.4.0 (6 November 2026)

Short automatic snapshot (`benchmarks/perf_snapshot.py`) of the 0.4.0 sources plus the
isolated `--benchmark-session` launch mode, built locally, on the same M3 Max MacBook Pro.
Menlo 13, the observer's fixed window frame, `/bin/zsh -f` shells, default settings
(resource footer on). One run; launch timings are warm and noisy. Raw data:
[baseline-0.4.0.json](2026-11-06-snapshot/baseline-0.4.0.json).

| Check | 0.4.0 |
|---|---|
| Warm launch to first window | 0.544 s median (0.516 / 0.544 / 0.700) |
| 1 tab idle | 53.6 MiB footprint · 0.02 % CPU · 1.0 wakeups/s |
| 3 tabs idle (2 hidden) | 110.9 MiB footprint · 0.00 % CPU · 0.0 wakeups/s |

Each hidden tab adds about 29 MiB, almost all of it the terminal view's retained
drawing surfaces (IOSurface), not scrollback. Wakeups use `ri_interrupt_wkups`; the
3-tab window was not frontmost during sampling, so its footer sampler was paused.
Typing latency is not part of the snapshot; see the 0.1.2 report for the manual method.
